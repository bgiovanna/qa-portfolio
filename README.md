# QA Testing Portfolio Project

This repository contains a QA testing project created to demonstrate testing practices including:

- Test planning
- Test case design
- Bug reporting
- API testing
- Test execution reporting

The project simulates the testing process for a demo web application.

## Tools Used

- Postman
- Browser DevTools
- Manual Testing
- SQL (conceptual validation)

## Project Scope

The scope of this testing project focuses on the authentication module (Login functionality) of a demo web application.
